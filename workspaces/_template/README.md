# Workspace Template

Copy this directory to `workspaces/<unique-id>/` or use `/workspace`.

The template is intentionally domain-neutral. Adapt terminology and local structure only after the work reveals what is useful.

## Required

- `WORKSPACE.yaml`
- `context/CURRENT.md`

## Optional layers

- `memory/` for history and learnings
- `inbox/` for unclassified incoming material
- `knowledge/` for durable workspace-specific understanding
- `assets/` for source files or reusable artifacts
- `decisions/` for settled choices and reasoning
- `outputs/` for deliverables
- `automations/` for workspace-scoped cadence
- `skills/` for capabilities that are not yet shared/global

The workspace manifest should point to authoritative external sources rather than copying them unnecessarily.
