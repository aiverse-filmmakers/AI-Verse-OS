# AI-Verse 3D Brain

Local visual knowledge explorer generated by the AI-Verse OS `/3d-brain` skill.

## Run

```bash
node build.mjs
node serve.mjs
```

Open `http://127.0.0.1:4640` unless `brain.config.json` specifies another port.

## Files

- `brain.config.json`: local brain name and approved source categories
- `build.mjs`: scans configured Markdown/text sources and creates `graph.json`
- `graph.json`: generated graph data
- `serve.mjs`: local HTTP server
- `index.html`, `style.css`, `app.js`: local visual interface

The builder never changes source notes. Generated graph data may reveal filenames or titles from private notes, so review before publishing the generated app.
