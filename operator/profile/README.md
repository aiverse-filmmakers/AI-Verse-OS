# Operator Profile

Store relatively stable facts and working preferences here.

Suggested files created by `/onboard` when supported by evidence:

- `identity.md` - who the operator is, roles, responsibilities, relevant background
- `preferences.md` - how the AI should work, communicate, format, ask, and seek approval
- `goals.md` - current medium-term outcomes that span workspaces
- `voice.md` - optional real writing/communication samples and derived guidance when writing on the operator's behalf matters

Do not invent traits from style stereotypes. Do not copy whole workspace histories into the profile.
