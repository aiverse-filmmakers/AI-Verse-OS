# Apps

Apps are persistent interfaces or tools built on top of AI-Verse OS.

An app may visualize, edit, monitor, or trigger work, but important canonical state should remain in the appropriate operator, workspace, knowledge, connection, or decision source.

Avoid hidden app-only truth. If the app is deleted, the OS should still retain its important knowledge and reasoning.

The optional `/3d-brain` capability generates an app under this layer.
