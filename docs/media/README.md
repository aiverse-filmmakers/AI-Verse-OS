# 3D Brain demo

`3d-brain-demo.mp4` is the supplied 35.87-second, 1080p recording of the original full 3D Brain experience. It is preserved unchanged so the visual result and behavior remain available as a reference.

`3d-brain-preview.gif` is a 640-pixel-wide, five-frame-per-second preview of that recording. The main README shows this looping preview and links it to the full video.

The recording illustrates the result using an example knowledge set. A real AI-Verse OS skill run uses the user's chosen name, categories, and actual local sources.
